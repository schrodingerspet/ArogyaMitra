# ArogyaMitra Frontend

React + Vite frontend for the ArogyaMitra platform.

## Setup

```bash
npm install
cp .env.example .env
```

Set `VITE_API_BASE_URL` in `.env` to your backend URL.

## Run

```bash
npm run dev
```

Default local URL: `http://127.0.0.1:5173`

## Build

```bash
npm run build
```
